# 💰 SMART BUDGETING WEB APP FOR STUDENTS

A simple and user-friendly web application designed to help students manage their finances efficiently. This app allows users to track income and expenses, set budgets, and monitor savings in an organized way.

---

## 🚀 Features

### 🔐 Authentication
- Secure login system (Username & Password)
- Session-based access
- Logout functionality

### 🏠 Dashboard (Default Page)
- Total Balance 💰
- Total Expenses 💸
- Total Savings 📈
- Expense Pie Chart
- Recent transactions
- Budget progress bar
- Alerts

### ➕ Add Transaction
- Amount
- Category
- Date
- Description

### 📄 View Transactions
- View all records
- Filter by category and month

### 🎯 Set Budget
- Set monthly budget
- Track spent and remaining amount
- Progress bar and alerts

### 🔍 Search Functionality
- Search by category
- Description
- Amount
- Date

### 👤 Profile
- View details
- Update profile
- Change password

### 🔔 Alerts System
- Low balance alert
- Budget limit alert

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL

---

## ⚙️ How It Works

1. User logs in using valid credentials
2. Dashboard loads by default
3. User can add transactions, view or search transactions, and set budget
4. Data is stored in the database
5. Dashboard updates automatically
6. Alerts notify the user about spending limits

---

## ▶️ How to Run

1. Download or clone this repository
2. Open the project folder
3. Run the index.html file in your browser
4. Login and start using the application

---

## ✨ Conclusion

The SMART BUDGETING WEB APP FOR STUDENTS provides a simple and effective way for students to manage their finances. It helps users track spending, stay within budget, and make better financial decisions.
